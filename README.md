Project Overview
AEROBRAIN is an independent project built to demonstrate enterprise-grade AI integration in a high-stakes industry. It replaces manual parts lookup with an intelligent, conversational interface, complete with real-time inventory tracking, digital twin monitoring, and blockchain-verified part traceability.

Key Features (As Implemented in Code)

- AI Concierge Chat: Real-time, NLP-driven chatbot logic for part queries, compatibility checks, predictive alerts, and dynamic pricing.
- Visual Part Identification: Drag-and-drop image upload UI with simulated neural network analysis (identifies part numbers, condition, and compatibility).
- Global Inventory Network: Interactive HTML5 Canvas-based map tracking live warehouse stock across Nairobi, Dubai, Amsterdam, and Singapore.
- Digital Twin Monitoring: Real-time animated engine health metrics (Core Temp, RPM, Health %, Remaining Life) using Canvas API.
- Blockchain Traceability: UI integration displaying hashed verification badges for part provenance and OEM certification.
- Futuristic UI/UX: Custom-built glassmorphism and neon-cyberpunk design system with CSS variables, smooth animations, and a cinematic boot sequence.

Tech Stack

- Frontend: HTML5, Advanced CSS3 (Grid, Flexbox, Custom Properties, Keyframe Animations), Vanilla JavaScript (DOM manipulation, Canvas API, FileReader API).
- Backend/Logic: Python (serving the application structure and data payloads).
- Design Philosophy: Mobile-responsive, accessibility-conscious, and performance-optimized (zero external JS framework dependencies for core logic).
